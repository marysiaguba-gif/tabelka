## Szczegółowa tabela czasu – projekt „GamesZone”

| Etap pracy | Co dokładnie było robione | Szacowany czas |
|------------|---------------------------|----------------|
| Pomysł i plan | Wymyślenie wyglądu strony, układu i funkcji | 1–2 h |
| Budowa HTML | Stworzenie struktury strony (header, sidebar, lista gier, modal) | 2–3 h |
| Podstawowy CSS | Dodanie kolorów, czcionek, tła i ogólnego wyglądu | 2–3 h |
| Stylowanie UI | Efekty hover, glow, cienie i dopracowanie wyglądu | 2–4 h |
| Responsywność | Dostosowanie strony do telefonów i mniejszych ekranów | 1–2 h |
| JavaScript | Wyświetlanie gier i działanie strony | 2–3 h |
| Wyszukiwarka | Filtrowanie gier po nazwie | 1–2 h |
| Kategorie | System filtrowania po typach gier | 1–2 h |
| Sortowanie | Sortowanie gier A-Z i Z-A | 1 h |
| System ulubionych | Dodawanie gier do ulubionych i LocalStorage | 2–3 h |
| Licznik ulubionych | Wyświetlanie liczby polubionych gier | 0.5–1 h |
| Modal | Okno ze szczegółami gry po kliknięciu | 2–3 h |
| Dodawanie danych | Wpisywanie nazw, opisów, zdjęć i linków | 3–6 h |
| Animacje | Efekty przejść i interakcje | 1–2 h |
| Testowanie | Poprawianie błędów i sprawdzanie działania | 2–4 h |

## Łączny czas
Około 25–40 godzin pracy.
